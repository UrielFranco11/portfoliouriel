## Contact form setup

Before publishing with GitHub Pages, replace `TU_CORREO@EJEMPLO.COM` in the
`data-contact-email` attribute at the top of `index.html` with your real email
address. The form sends the details through FormSubmit directly to that inbox;
the first delivery asks you to confirm the recipient address. If that service
is unavailable, it opens the visitor's email client as a fallback, and the
**Copiar mensaje** button is available too.
